# Expense Tracker

A full stack expense tracking app built with Node.js, Express, MongoDB, and JWT authentication.

## Live Demo
🌐 [https://vidushi-expense-app.netlify.app](https://vidushi-expense-app.netlify.app)

## Features
- User registration and login
- JWT authentication
- Add, view, and delete expenses
- Financial summary with balance

## Tech Stack
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express
- **Database:** MongoDB Atlas
- **Auth:** JWT + bcrypt
- **Deployed on:** Netlify + Railway
